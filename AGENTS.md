# Project Guidelines

## Docs (vimdoc)

- `doc/terminals.nvim.txt` is generated by panvimdoc (see `.github/workflows/docs.yml`); CI fails if it differs from a fresh run.
- The generator bumps the `Last change:` date on every run, so even code-only commits go stale when pushed on a new day.
- Never fix a stale vimdoc with a separate docs commit. Refresh `doc/` and amend it into the same commit being pushed.
